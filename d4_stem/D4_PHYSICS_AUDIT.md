doe_experiments/phase_codec.py, png_io.amplitude_to_u8. Grid: x = (n - N//2)*dx, N=128, dx=dy=10 um; output pitch
lambda z/(N dx) per z; lambda 532 nm, z 24.1/25.3/26.5/27.7 mm.

Analytic reason: with centred indices m, p in {-64..63} (mod 128) the single-FFT Fresnel is
  U_out(p) = s(z) * c_out(p) * sum_m exp(-2 pi i p.m/N) c_in(m) U(m),  c_in/c_out depend only on |m|^2, |p|^2,
and the kernel is separable with identical x/y factors (dx = dy, H = W). The index maps m -> -m (mod N) per axis and
the transpose leave exp(-2 pi i p.m/N), |m|^2, |p|^2 invariant (the unpaired index -64 maps to itself, (-64)^2 = 64^2).
Hence F_z(g U) = g F_z(U) EXACTLY for the 8 D4 elements generated by these maps — complex field, no global phase or
gauge factor — at every z, and the same for inverse_fresnel; STEM features (T, Re/Im inverse(T)/rms) commute because
rms is permutation invariant. The pixelwise codec and per-plane max display policy commute as well.

Group: closed, inverses, 8 distinct elements (both conventions). Codec (c64): encode(g phi) == g encode(phi) exactly;
DOE.png -> decode -> 4 Fresnel -> official uint8 display: max 0 code difference vs transformed display.
Verdict: D4_PHYSICS_PASS for c64; standard flip/rot90 about the pixel centre (c63.5) is NOT an exact symmetry (FAIL).

Data-distribution caveats (not physics): (1) under c64 the row/column with index 0 is mapped onto itself, so a
reflected target keeps its first row/column in place (1-pixel seam vs. a pure mirror); (2) synchronised reflections
produce mirrored glyphs/text and rotated stripe angles — physically valid quartets, but not guaranteed to be in the
TRAIN/VAL/organiser distribution; (3) transformed views are correlated, not 8 independent samples; (4) the network
(conv + replicate padding + pooling) is not itself equivariant, which is why augmentation can change training.
