# Правила агентов Nuclear DOE

Перед работой прочитать свою GitHub Issue, docs/INTERFACES.md и docs/COORDINATION.md. GitHub — источник задач, согласований и результатов. Работать в собственной ветке от main и только в путях своей Issue. Общие типы, __init__.py, зависимости, workflow и документацию контракта меняет координатор. Не исправлять чужую ветку и не перезаписывать чужие изменения.

Контракт: [B,1,H,W], метры, радианы, autograd; ASM возвращает комплексное поле, интенсивность без скрытой нормировки. Точные сигнатуры и правила нормировки — в docs/INTERFACES.md; общий импорт из doe_core.contracts. Временный stub в тесте не является готовым физическим модулем. Любое изменение интерфейса сначала согласовать через Issue/PR.

Одна Issue — одна ветка codex/<issue>-<slug> — PR в main. До публикации выполнять относящиеся к изменению тесты; в PR указывать фактические команды, результаты и пропуски. Не сливать непроверенный код. Ревью и зелёные checks обязательны по процессу команды, даже когда тариф GitHub не обеспечивает branch protection. Не заявлять выполненным отсутствующий тест, физическую корректность или ручную приёмку.

Не запускать платные API/вычисления, опасные команды, массовое обучение или загрузку больших данных без согласования Павла. Не добавлять секреты, датасеты, checkpoints и сгенерированные результаты в git. Не затрагивать Foundation AI и nuclearhack-transcriber.

Приоритет официального кейса: P0 single-FFT Fresnel + multi-plane Adam + PNG/Pearson/SSIM; P1 обученная нейросеть; P2 GS/гибрид/UI/дополнительные исследования. ASM сохраняется отдельно. Не расширять объём Issue самостоятельно. При неоднозначности сначала проверить контракт/Issue; фиксировать блокировку и один конкретный вопрос, продолжая независимую работу.

Официальный кейс и предложенный v1: docs/CASE_REQUIREMENTS.md, docs/INTERFACES_V1.md. Для нового конкурсного пути обязательны4targets->[однаphase]->4single-FFT Fresnel, 8-bitDOE roundtrip и Pearson/SSIM. Приоритеты: P0 Fresnel/multi-planeAdam/PNG/метрики; P1 обученнаянейросеть; P2 GS/гибрид/UI. До согласования и merge v1 владельцы не меняют публичные API. v0/ASM сохраняется отдельно.
