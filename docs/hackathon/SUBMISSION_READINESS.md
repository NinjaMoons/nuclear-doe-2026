## Передача судьям

1. Капитан сверяет в закрепе трека допустимость отдельного Git-репозитория и способ раздачи весов. Если разрешён отдельный репозиторий, локальный комплект можно развернуть как новую чистую Git-историю после согласования доступа и прав. На организационном приватном Git дать судьям минимальную роль чтения. Публичный вариант требует явного разрешения на публикацию проверенного состава файлов.
2. Веса доступны в локальном комплекте. Приватный draft `data-4b-v1` содержит WhiteCollars и исследовательские файлы. Не публиковать его целиком. При согласованном размещении использовать адрес, с которого их действительно может скачать судья. Приватный draft не использовать как единственный канал. [Доступ к draft-релизам](https://docs.github.com/en/rest/releases/releases#list-releases).
3. Если организаторы требуют текущий репозиторий, владелец подтверждает точные GitHub-логины, объём разрешённого доступа и способ передачи весов. Прямой collaborator в личном приватном репозитории получает запись. Не приглашать в основной репозиторий ради доступа на чтение. [Права в личном репозитории](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository).
4. Проверить клонирование и скачивание весов из аккаунта судьи или эквивалентного разрешённого аккаунта без прав команды. Сверить SHA256 весов. Проверка под администратором не закрывает этот пункт.

В локальном комплекте только разрешаемые к рассмотрению файлы из точного V2, синтетические входы и результаты smoke, README, два gate и манифест. Отдельно сохранены оригинальные внутренние пакеты. TEST, VAL PNG, чужие данные, исследовательские веса, история Git, личные пути из логов и диагностический Adam в комплект для судей не вошли. Код общей библиотеки Adam присутствует как зависимость неизменённого runtime и используется в синтетическом тесте формата. Команда нейросетевого запуска не вызывает синтез Adam.

- Дополнительная информация:

> STEM V2 синтезирует одну фазовую маску из четырёх целевых амплитуд одним проходом обученной сети. После записи и чтения DOE.png выполняется однократная реконструкция Френеля на каждом из четырёх расстояний. Комплект содержит закреплённые зависимости, веса с SHA256, синтетический пример и команды воспроизведения. Итеративного уточнения маски при конкурсном запуске нет.

После отправки капитан сохраняет экран или письмо подтверждения, время МСК и ID/URL формы, точную отправленную Git-ссылку с commit/tag и SHA256 размещённого ZIP/весов. Сведения о команде не дублировать в Issue. Координатор фиксирует квитанцию в #8 только после её получения.
