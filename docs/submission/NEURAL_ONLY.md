## Как получается маска

FourInputUNet принимает четыре амплитудных изображения в порядке z, тензор [B, 4, 1, 128, 128]. Сеть предсказывает одну общую фазу [B, 1, 128, 128] в радианах. Конкурсный CLI загружает фиксированные веса и делает один forward в eval/no_grad. Сохранённый DOE.png — квантование этого выхода. После декодирования фазы одношаговый Fresnel FFT рассчитывает четыре амплитуды |U|. Метрики и диагностическое восстановление до квантования не меняют маску. Классический solver вызывается отдельным subcommand adam. [Проверенный runtime 6785eca](https://github.com/NinjaMoons/nuclear-doe-2026/tree/6785eca6e5c7f94a914214c1aac5bd5984792824)

## Проверка точного runtime

Из архива 6785eca выполнен один CPU neural CLI на четырёх новых синтетических PNG. Обёртка посчитала один вызов FourInputUNet.forward и блокировала создание оптимизатора, backward, классический solver и subprocess. DOE.png побайтно совпал с квантованием выхода forward. Все четыре восстановления и метрики проверены по сохранённым L8 PNG. Независимый пересчёт в фактическом домене загрузки PNG дал максимальное абсолютное расхождение 4,44·10⁻¹⁶. ## Команда для конкурсной четвёрки

Из распакованного runtime с Python 3.12 и закреплёнными CPU зависимостями.

~~~text
python -m doe_experiments.cli neural --checkpoint <best.pt> --targets <z1.png> <z2.png> <z3.png> <z4.png> --output-dir <new-dir>
~~~

Файлы входа — L8 PNG 128×128. Порядок 24,1 / 25,3 / 26,5 / 27,7 мм сверяется с разметкой организаторов. Имена в команде условны. Выходы DOE.png, reconstructed_01.png–reconstructed_04.png, metrics.json и manifest.json. Pearson и глобальный SSIM рассчитаны по командной реализации. Точная процедура evaluator и канал загрузки ждут подтверждения.
