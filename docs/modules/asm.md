# doe_core/asm.py — angular spectrum method (Issue #2)

Статус: реализация по контракту v0 (`docs/INTERFACES.md`, PR #9). Полного ТЗ нет: все геометрии ниже — **example/тестовые фикстуры**, не конкурсные параметры.

## API

```python
from doe_core.asm import propagate, intensity
from doe_core.contracts import OpticsConfig

out = propagate(field, OpticsConfig(wavelength_m=532e-9, pixel_pitch_m=(8e-6, 8e-6),
                                    distance_m=2e-2, pad_factor=4))
I = intensity(out)  # |out|^2, без нормировки
```

- `field`: complex64/complex128, `[B,1,H,W]`, B>=1, H,W>=2, конечные значения. Результат — та же форма, dtype и device; autograd сохраняется (нет detach/numpy в пути).
- `intensity`: `real^2 + imag^2` (градиент определён и в нуле), вещественный dtype, соответствующий комплексному.
- Ошибки входа (не Tensor, не комплексный dtype, неверная форма, NaN/Inf, `config` не `OpticsConfig`) — `ValueError`.

## Оператор

`U_out = crop(IFFT2(H · FFT2(pad(U_in))))`, `fft2/ifft2` по `(-2,-1)`, `norm="ortho"`, сетки частот — unshifted `fftfreq(n, d=pitch)`.

`H = exp(i·2π·z·kz)`, `kz = sqrt(1/λ² − fx² − fy²)`, ветвь `Im(kz) >= 0`. Реализовано явно: распространяющиеся частоты — `|H|=1`, фаза `2πz·kz`; эванесцентные — `H = exp(−2πz·sqrt(fx²+fy²−1/λ²))`. В коде `sqrt(abs(arg))` с отдельной маской знака `arg >= 0`: это явное разделение двух ветвей, без комплексного sqrt; вещественный sqrt от отрицательного числа не вычисляется.

- `H` считается в float64 на CPU заново при каждом вызове (без кэша), затем приводится к dtype/device поля. Кэш убран после ревью PR #13: тензор, созданный под `torch.inference_mode()`, ломал последующий autograd (регрессия `test_inference_call_does_not_break_later_autograd`). Причина: фаза `2πz/λ ≈ 1.2e6` рад при z=0.1 м; в float32 ошибка фазы была бы ~0.1 рад. complex64 и complex128 совпадают с отн. ошибкой 1.8e-7 (тест).
- `distance_m == 0` → `field.clone()`: точное тождество, включая эванесцентную полосу.
- `pad_factor == 1` — периодическая область. `> 1` — нули до `factor·(H,W)`, начало окна `(factor·n − n)//2` (нечётный остаток снизу/справа), после распространения вырезается то же окно; pitch не меняется. На периодической сетке оператор эквивариантен к сдвигу, поэтому положение окна не влияет на результат crop.
- Band limit не применяется (не меняем оператор неявно). Мощность не перенормируется: после crop и затухания она может быть меньше входной.

## Дискретизация и допустимые параметры

`H` дискретизирована с шагом `Δf_x = 1/(P_x·dx)`, `Δf_y = 1/(P_y·dy)`, где `P = pad_factor·N` по каждой оси. Нужно, чтобы фаза `φ(fx,fy) = 2πz·sqrt(1/λ² − fx² − fy²)` менялась меньше чем на π между соседними FFT-бинами по обеим осям на всей используемой спектральной поддержке (Matsushima & Shimobaba, Opt. Express 17, 19662 (2009), https://doi.org/10.1364/OE.17.019662).

**Одномерная граница недостаточна.** Формула `z <= (P·pitch/2)·sqrt(4·pitch²/λ² − 1) ≈ P·pitch²/λ` выведена для одной оси при второй частоте = 0. В 2D `∂φ/∂fx = −2πz·fx/sqrt(1/λ² − fx² − fy²)`, и ненулевая `fy` уменьшает знаменатель. Контрпример (ревью PR #13, тест `test_axial_rule_misses_diagonal_aliasing_corner_bound_catches_it`): N=64, dx=dy=λ, pad 1, z=50λ — осевая граница 55.43λ пропускает, но между угловыми бинами `(−32/64, −32/64)/λ` и `(−31/64, −32/64)/λ` прирост фазы 3.39 рад > π.

**Достаточная 2D-граница (угловая).** Если весь спектральный прямоугольник распространяется, т. е. `R = 1/λ² − 1/(2dx)² − 1/(2dy)² > 0`, то `|∂φ/∂fx|` максимальна в углу, и по теореме о среднем достаточно

```
z <= min(P_x·dx², P_y·dy²) · sqrt(R)
```

(для pitch >> λ это ≈ min(P·pitch²)/λ, т. е. близко к старой оценке). Тест `test_corner_bound_is_sufficient` проверяет на трёх сетках (включая dy≠dx и pitch ~λ), что при этой z фактический максимальный прирост ≤ π. Пример: N=64, pitch=8 мкм, λ=532 нм → ≈ 7.7 мм при pad 1, ≈ 30.8 мм при pad 4.

**Около grazing/evanescent границы** (`R <= 0`, pitch ≲ λ/√2) замкнутой границы нет: производная фазы растёт без ограничения при `fx² + fy² → 1/λ²`. Тогда проверять численно: вычислить `φ` на фактической сетке бинов и максимум `|Δφ|` между соседними распространяющимися бинами по каждой оси (функция `max_transfer_phase_step` в тестах). Если спектр поля реально ограничен, проверку можно делать только по его поддержке, но это нужно обосновать для конкретного поля.

Второе условие — окно: дифрагировавшее поле должно оставаться внутри padded области, иначе периодическая заворачиваемость портит результат. Его проверяем сходимостью по `pad_factor` для конкретной геометрии.

Правило для отчётных сравнений: угловая граница (или численная 2D-проверка приростов фазы) выполнена **и** изменение интенсивности в окне между `pad_factor` p и 2p < 1e-3 (отн. L2). Это необходимые проверки дискретизации, а не гарантия пригодности: параметры, не прошедшие их, не использовать. Если для нужных параметров условия недостижимы при разумном размере сетки, нужен band-limited ASM — отдельное решение координатора с изменением контракта.

Пример (тест `test_padding_converges_for_example_preset`): N=64, 8 мкм, 532 нм, квадратная апертура 16×16 px, z=20 мм. Отн. L2 интенсивности к pad 16: pad 1 — 1.6e-1, pad 2 — 1.6e-3, pad 4 — 1.5e-5, pad 8 — 6.8e-7. Pad 1 для этой геометрии непригоден, pad ≥ 4 сходится. В окне остаётся ~94% мощности.

## Почему собственная реализация, а не TorchOptics/waveprop

По D-005 (`docs/research/decisions.md`, PR #11) адаптер допустим только при точном выполнении контракта и согласованных зависимостях. Обе библиотеки добавили бы зависимость, которую меняет только координатор, и отличаются семантикой padding (`asm_pad` TorchOptics — отсчёты с каждой стороны; waveprop по умолчанию bandlimit). Поэтому сделан минимальный ASM на уже согласованном PyTorch 2.9.0. **Численное сравнение с TorchOptics (закреплённый SHA, приёмка #2) НЕ выполнено**: нужна проверочная среда с библиотекой, которую согласует координатор; общие requirements автор не меняет. Это открытый пункт приёмки #2. После решения о кейсе ASM — дополнительный оператор, не конкурсный forward (конкурсный — single-FFT Fresnel, #14).

## Ограничения

- Скалярная модель, однородная среда, одна плоскость. Поляризация, высокая NA и многоплоскостные/3D ДОЭ не проверялись.
- Нет band limit: при `z > z_max` и широком спектре возможен алиасинг; проверка — по правилу выше.
- Интенсивность — дискретная сумма `|U|²` без площади пикселя `dy·dx`; для физической мощности умножать явно.
- Скорость не измерялась. Реальной оптики/стенда нет, валидация только численная.
