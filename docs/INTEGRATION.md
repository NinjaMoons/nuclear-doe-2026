## Предположения, требующие сверки с полным ТЗ
Полного официального задания ещё нет. Ни один параметр ниже не заявляется требованием организаторов:
- скалярная монохроматическая когерентная волна, однородная среда; wavelength_m уже длина волны в среде;
- один фазовый ДОЭ, фиксированная единичная входная мощность, одна выходная плоскость; амплитудные/многоплоскостные/3D задачи пока не покрыты;
- wavelength 532 nm, dy=8 um, dx=9 um, расстояние 10 mm — только стартовый проверочный пресет;
- базовые synthetic targets не доказывают соответствие конкурсным данным; нужны сведения о данных, допустимых сетках/параметрах, ограничениях изготовления и метриках жюри;
- пока bandlimit не включён, допустимость sampling для каждого пресета нужно доказать; совпадение двух ASM не исключает общий aliasing;
- после padding/crop/evanescent decay мощность выходного окна не обязана равняться входной; roi_efficiency относится к этому окну;
- deadline 7 ноября 21:00 МСК — рабочий срок timeline сайта, срок конкретного кейса ещё не подтверждён.

## План первого физического эксперимента
1. На CPU complex128 сформировать равномерное поле A=1/sqrt(HW) и real фазовую маску. Сначала нулевая фаза и одна дискретная Fourier-mode, затем seed-local случайная фаза. Аналитические тесты — малая периодическая сетка, отдельные propagating и evanescent случаи. Эти тесты принадлежат #2.
2. Проверить z=0 identity и известный exp(+ikz*z)/затухание, dy!=dx, odd/even прямоугольники, разные batch-поля, autograd gradcheck. На periodic propagating спектре проверить мощность; на cropped окне использовать правильный баланс.
3. Для начального изображения использовать target от make_targets(seed=11). Smoke работает с B=2, 32x40, pad_factor=1; он проверяет соединение API, а не физическую валидность открытого пространства. Для демо начать с 128x128, pad_factor=2 и отдельно оценить сходимость при 3; если пресет не проходит sampling/convergence, изменить его с явной записью причины.
4. Синтезировать фазу Adam(seed=17, lr=0.05), 32 шага для smoke, до 100 для первого demo после оценки времени. Сравнить нормированный MSE до/после, cosine и ROI. Возвращённую фазу повторно распространить и сверить с возвращённой intensity.
5. Получить четыре панели: target, начальная intensity, phase в радианах, итоговая intensity; отдельно loss_history и численные метрики/время. Никакой отдельной реализации физики в UI. Сам screenshot не является доказательством корректности.

## Интеграционный smoke
Файл: tests/integration/test_baseline_smoke.py. Пока модулей нет, обычный CI явно показывает skipped; 8 инфраструктурных тестов не становятся научными. Когда все четыре файла есть, import/runtime/assertion ошибки не маскируются importorskip. На обязательной контрольной точке отсутствие модуля — ошибка:
```powershell
$env:DOE_REQUIRE_BASELINE = '1'
python -m pytest tests/integration/test_baseline_smoke.py -q -s
Remove-Item Env:DOE_REQUIRE_BASELINE
```
В PowerShell использовать python из своего venv; научные зависимости ставить по README. Тест проверяет data -> ASM -> Adam -> metrics, формы/dtype/device, конечность, согласованность возвращённых фазы/интенсивности и снижение batch loss. Численные критерии будут реально проверены после получения модулей; текущий skip не является успешной интеграцией.

## Готовые библиотеки и решение #2
Выбран B: короткий контрактный оператор на готовых FFT/autograd PyTorch, TorchOptics — независимый reference. Вариант A возможен, но публичный Field имеет global dtype, другое padding и AUTO/resampling; это требует более сложного адаптера для нашего точного контракта.

Первичные источники закреплены в [обновлённой Issue #2](https://github.com/NinjaMoons/nuclear-doe-2026/issues/2). TorchOptics ([ASM](https://github.com/MatthewFilipovich/torchoptics/blob/34fe9c40f874e53db225e703c5580befe8c523b5/src/torchoptics/propagation/angular_spectrum_method.py), [utils](https://github.com/MatthewFilipovich/torchoptics/blob/34fe9c40f874e53db225e703c5580befe8c523b5/src/torchoptics/utils.py)) MIT, torch/matplotlib. Reference сравнение выполнять в отдельном процессе по dtype с внешним одинаковым padding/crop, forced ASM, asm_pad=(0,0). Библиотеку фиксирует координатор в проверочной среде; численный reference ещё не запускался.

waveprop MIT, но API 2D и odd grid/padding отличаются; подходит дополнительный reference на согласованной чётной сетке. Neural Holography не брать за runtime: старый стек, real sqrt/обязательный bandlimit и отличающиеся root/header лицензии с ограничениями academic/noncommercial. Исходники проверены, скорости и численное соответствие пока NEEDS_TEST. Существующий исследовательский PR #11 не изменять и не объединять в рамках этого поручения.
