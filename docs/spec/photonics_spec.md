# AI-фотоника — условия задачи (со слайдов постановки, 06.11)

Источники: видео `~/Downloads/Telegram Desktop/video_2026-11-07_00-13-23.mp4` (слайды 5–6 переписаны дословно) + диктофон (см. `photonics_qa_2026-11-06.md`).

## Задача
Создать нейросеть, которая синтезирует **фазовый ДОЭ (голограмму)**. Свет, прошедший через ДОЭ, должен формировать 3D-сцену из **4 изображений на разной глубине**: ставишь экран на расстояние 1, 2, 3, 4 и видишь изображения 1, 2, 3, 4.

## Условия-1: исходные параметры
- **Объектные изображения:** 4 шт., 128×128 пикселей.
- **ДОЭ:** фазовый, 128×128, значение каждого пикселя от −π до π, соответствует 4 исходным изображениям.
- **Восстановление:** прямой расчёт дифракции Френеля через выражение **с одним преобразованием Фурье**.
  - расстояния: **24.1 мм; 25.3 мм; 26.5 мм; 27.7 мм** (изображения 1–4)
  - длина волны: **532 нм**
  - пиксель ПВМС (SLM): **10 мкм**

## Условия-2: результаты
**Вход сети:** 4 изображения, 128×128, 8 бит, одноканальные (не RGB), PNG.

**Выход:**
1. ДОЭ как изображение: 128×128, 8 бит, одноканальный, PNG; пиксель 0 = −π, 255 = +π.
2. 4 восстановленных изображения: 128×128, 8 бит, одноканальные, PNG. Получены восстановлением из синтезированного ДОЭ численным расчётом дифракции Френеля.
3. Значения 2 метрик попарно (исходное ↔ восстановленное, для каждого из 4):
   - коэффициент корреляции Пирсона
   - индекс структурного сходства (SSIM)

**Финальные материалы для экспертов:** всё созданное (код, наборы данных и т.д.).

## Ответы постановщиков
- **Что на картинках — не обязательно цифры.** Цифры на слайде — пример из статьи. Тестовая сцена будет **сложнее**, но тоже 4 объекта. Дают её только при проверке/защите.
- Датасет для обучения делаем сами (любые изображения / синтез).
- Архитектура, размер модели, время инференса — на наше усмотрение; время не оценивается.
- Главный и единственный критерий — качество восстановленных изображений (корреляция + SSIM).
- Вопрос «чем отличается от Герчберга–Сакстона/итеративных методов» — ответ размытый: проверяют результат, критерий — качество. Но решение должно быть **нейросетевым** (так сформулирована задача).
