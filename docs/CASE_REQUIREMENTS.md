Источник: [полная презентация, 7 слайдов](spec/AI-photonics-case.pdf), предоставлена Павлом 6 ноября 2026. SHA256 A2E4DED9E35CF1B13D3C807B171AD7B50BA946756A7C4A9C09F9DC4E0A46422A. Прочитаны все слайды, формулы сверены визуально.

| Слайды | Обязательное требование | Изменение v0 |
|---|---|---|
| 2,5 | Single-FFT Fresnel, lambda=532nm, input pitch10um, z=24.1/25.3/26.5/27.7mm | Отдельный Fresnel; ASM остаётся дополнительным оператором |
| 5,6 | Четыре входных PNG128x128 uint8 grayscale, фиксированное соответствие z | Квартет [B,4,1,128,128] |
| 5,6 | Один общий фазовый DOE128x128 [-pi,+pi] | Одна фаза [B,1,128,128], не четыре независимых решения |
| 6 | DOE.png uint8 grayscale, 0=-pi,255=+pi | Фиксированный phase codec /255 и roundtrip |
| 6 | Четыре восстановленных PNG128x128 uint8 grayscale из сохранённого DOE | Decode DOE.png -> четыре Fresnel -> PNG -> reload -> metrics |
| 3,6 | Pearson и SSIM каждой из четырёх пар | MSE/cosine/ROI не заменяют эти метрики |

Точные входные четыре PNG пока не предоставлены. Временные квартеты маркировать synthetic/test; не выдавать картинки из демонстрационного слайда4 за конкурсные входы. Конкурсный срок в презентации не указан; прежний срок сайта 7 ноября21:00МСК требует подтверждения для кейса.

Не определены презентацией: начало координат чётной сетки, illumination amplitude, отображение интенсивности в uint8, параметры/окно SSIM, поведение Pearson для констант, способ обучения/объём данных. Предложения команды явно выделены в [v1](INTERFACES_V1.md); это не требования организаторов.
