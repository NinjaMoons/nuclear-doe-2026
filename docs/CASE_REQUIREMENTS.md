## Что дают устные ответы и чего они не устанавливают

| Вопрос | Доступная опора | Рабочее решение |
|---|---|---|
| Финальная четвёрка неизвестна заранее | Q&A [01:51], [02:52] | Готовить запуск на четырёх новых PNG, не обучение на финальной четвёрке |
| Обучающие данные можно создавать | Q&A [02:52]: свои либо предоставленные постановщиками | Сохранять происхождение, hashes и раздельные splits собственного корпуса |
| Главный приоритет — качество | Q&A [00:00], [00:52] | Качество и устойчивость важнее оптимизации скорости; timing сохранять для воспроизводимости |
| Размер/параметры сети на усмотрение команды | Q&A [01:32] | Это не снимает наши вычислительные бюджеты и не доказывает отсутствие всех лимитов защиты |
| Скорость точно не входит в score | Так написано в конспекте; очищенный ответ говорит о приоритете качества и параметрах на усмотрение команды | ORAL_NOTE; точная формула score остаётся UNCONFIRMED |
| NN initializer + Adam/GS refinement | Однозначного ответа нет | Pure NN — основной проверенный путь; гибрид возможен отдельным будущим режимом, но не объявлен разрешённым конкурсным методом |

Фраза конспекта «главный и единственный критерий» сильнее доступной очищенной реплики «в первую очередь». Не приписывать организаторам неуказанные веса метрик/плоскостей, пороги, SSIM window или право fine-tuning на скрытых входах.

## Текущая стратегия команды

Павел подтвердил продолжение pure-NN пути: `4 PNG -> обученная сеть -> одна фаза -> DOE.png/reload -> 4 Fresnel amplitude PNG/reload -> Pearson/SSIM`. Улучшения качества выбираются на VAL, текущий TEST не становится набором подбора.

Гибрид не требует заново строить Fresnel, codec, PNG или метрики: сеть может дать начальную фазу тому же оптимизатору. Однако текущий Adam API начинает со случайной фазы и не принимает init_phase. Такое расширение принадлежит владельцу #3, требует отдельного PR/проверок и решения о применении; данный документ его не внедряет и нового обучения/эксперимента не разрешает. Pure NN результат остаётся отдельным воспроизводимым режимом.
