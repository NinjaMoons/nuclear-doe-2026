### 3. Математическое объяснение существенных рисков

Главная угроза предложенного loss заключается в математике производной функции по максимуму.
Пусть $I_m = \max(I)$ — интенсивность самого яркого пикселя. Нормированная интенсивность $J_i = \frac{I_i}{I_m}$.
Функция потерь для одной плоскости: $L = \frac{1}{N} \sum_i (J_i - T_i)^2$.

Посмотрим, как градиент распределяется на обычный пиксель $k \neq m$ и на пиксель-максимум $m$:

1. **Для обычного пикселя $k$:**
$\frac{\partial L}{\partial I_k} = \frac{2}{N I_m} (J_k - T_k)$.
Градиент масштабируется как $1/I_m$. Если спекл яркий, градиент на полезную структуру становится микроскопическим (vanishing gradient).
2. **Для пикселя-максимума $m$:**
Пиксель $I_m$ стоит в знаменателе у *каждого* $J_i$. По правилу сложной функции:
$\frac{\partial L}{\partial I_m} = \sum_{i \neq m} \frac{\partial L}{\partial J_i} \frac{\partial J_i}{\partial I_m} = -\frac{2}{N I_m^2} \sum_{i \neq m} I_i (J_i - T_i)$.

**Вывод:** Один случайный яркий спекл собирает на себе штраф от *всех $N=16384$ пикселей*. Нейросеть потратит весь ресурс оптимизатора на то, чтобы "погасить" этот один пиксель, вместо того чтобы выстраивать нужную дифракционную картину. Как только этот спекл погаснет, выскочит другой, и градиент резко сменит направление. Обучение будет хаотичным.

### 4. Минимальный воспроизводимый тест (MRE)

Этот скрипт доказывает проблему "стягивания градиента" и сравнивает max-нормировку с безопасной альтернативой.

```python
import torch

# Эмулируем интенсивность 128x128 после Fresnel. 
# Заполняем фоном 1.0, но добавляем один случайный интерференционный спекл (100.0)
I_max_norm = torch.ones(128, 128, requires_grad=True)
I_mean_norm = torch.ones(128, 128, requires_grad=True)

with torch.no_grad():
    I_max_norm[64, 64] = 100.0
    I_mean_norm[64, 64] = 100.0

# Целевое изображение (например, все пиксели = 0.5)
T = torch.full((128, 128), 0.5)

# --- Вариант 1: Предложенный командой (max) ---
J_max = I_max_norm / I_max_norm.max()
loss_max = torch.nn.functional.mse_loss(J_max, T)
loss_max.backward()

# --- Вариант 2: Альтернативный (mean) ---
# T_mean_scaled можно предрассчитать заранее
T_mean_scaled = T / T.mean() 
J_mean = I_mean_norm / I_mean_norm.mean()
loss_mean = torch.nn.functional.mse_loss(J_mean, T_mean_scaled)
loss_mean.backward()

# Измерения: отношение градиента на спекле к среднему градиенту на остальных пикселях
grad_max_speckle = I_max_norm.grad[64, 64].abs()
grad_max_others = I_max_norm.grad.abs().mean()

grad_mean_speckle = I_mean_norm.grad[64, 64].abs()
grad_mean_others = I_mean_norm.grad.abs().mean()

print(f"Max-Norm: Градиент на спекле больше фона в {grad_max_speckle / grad_max_others:.1f} раз")
print(f"Mean-Norm: Градиент на спекле больше фона в {grad_mean_speckle / grad_mean_others:.1f} раз")
# Критерий: если отношение > 100, обучение нестабильно, градиент ушел в один пиксель.

```

*Ожидаемый результат:* При max-нормировке соотношение будет порядка $10^4$ (градиент уничтожен для всего поля). При mean-нормировке соотношение будет адекватным $\approx 1$, градиент распределен равномерно.

### 5. Вердикт и минимальное изменение

**Вердикт:** Оставлять предложенный loss *нельзя*. Он заблокирует обучение при появлении первых же спеклов и приведет к энергетическому дисбалансу между четырьмя плоскостями.

**ОДНО минимальное изменение с обоснованием:**
Замените нормировку по `max()` на нормировку по энергии (или `mean()`), и соответственно отмасштабируйте таргеты.

*Было:*

```python
J_p = I_p / max(I_p)
Loss = mean((J_p - T_p)**2)

```

*Стало:*

```python
# T_p масштабируется так, чтобы его среднее равнялось среднему T из PNG 
# (или 1.0, если удобнее). Это делается 1 раз до цикла обучения.
J_p = I_p / mean(I_p) 
T_p_scaled = T_p / mean(T_p)
Loss = mean((J_p - T_p_scaled)**2)

```

**Обоснование:**
Среднее значение (или сумма) интенсивности $\sum I_p$ физически привязано к энергии входного поля $U_0$ и почти константно благодаря закону сохранения энергии. Производная $\frac{\partial}{\partial I_k} \text{mean}(I)$ распределяется равномерно ($1/N$). Это полностью устраняет уязвимость к единичным ярким пикселям, возвращает стабильные градиенты всей структуре ДОЭ и заставляет нейросеть честно распределять энергию между четырьмя $z$-плоскостями.
