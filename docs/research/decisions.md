## D-001 / R-001 — основной кандидат и независимый расчёт

**Решение:** начать ограниченный spike с **TorchOptics 1.0.2** как кандидатом основного физического движка; **waveprop 0.0.12** использовать как второй расчёт с явным bandlimit. **Состояние: условно принято для spike, production-выбор открыт до тестов.**

Основания: R-001-C01–C05, первичные S01/S02; PyTorch API, MIT у обоих, меньше объявленных runtime-зависимостей у TorchOptics. Это инженерная оценка, не установленное превосходство точности или скорости. В репозитории при первичном осмотре только README; работающего физического кода не найдено. При появлении кода сверить интерфейс перед изменениями.

- Явно указывать `propagation_method="ASM"`; AUTO может менять метод, ASM_FRESNEL меняет модель.
- Проверять padding по API конкретной версии, а не переносить числовое значение между библиотеками. TorchOptics `asm_pad` задаёт дополнение с каждой стороны; в проверенном коде default — 2N с каждой стороны, итог 5N, а не «pad до 2N».
- Не приравнивать TorchOptics ASM к BLAS. Сравнивать одинаковую модель, координаты, dtype, поддержку спектра, crop и нормировку; различия масок объяснять.
- Не копировать 30 строк собственного ASM из ответа в обход проверки готовых решений.
- Не менять общий requirements до воспроизводимого запуска. Точные torch/CPU/CUDA версии определяются целевой средой.
- Бюджет: 60–90 минут на первичный spike после доступности среды; замеры скорости/обучение не входят в обещание. Если установка/градиент/физическая приёмка не проходят — записать ошибку и рассмотреть waveprop как основной движок; существующий проверенный код сохранять.
- После ответов A/B и T0–T5 обновить решение, приложить отчёт. До этого результат **NEEDS_TEST**.

**Принято:** изучать и переиспользовать только после проверки конкретных лицензий, checkpoint/config и работы baseline. Не обещать перенос без обучения или гарантированный fine-tune. Ссылка в README не доказывает пригодность весов. R-001-C06–C09, R-003.

Копирование HoloNet/GS из Neural Holography пока не является заданием разработчикам. Статья/математический метод могут служить ориентиром; происхождение заимствований фиксировать. Простая замена импортов/слоёв не решает лицензионные вопросы.

## D-003 — минимальная физическая приёмка

**Принято как проект тестов, не выполнено:** API smoke → zero-distance/plane wave → энергетический баланс → градиент → сходимость сетки/окна → второй метод с другой ошибкой дискретизации. Конкретный протокол в test-plan.md должен получить независимую рецензию B.

Численные пороги в плане — предварительные инженерные значения для выбранных фикстур. Они не заменяют оценку допустимой ошибки по конкурсному кейсу. Запрещено нормировкой скрывать потери на crop/bandlimit.
