# R-001 — минимальный воспроизводимый эксперимент

> Актуализация после официального ТЗ (2026-11-06): обязательный путь — одна маска 128×128, четыре плоскости и одношаговый Fresnel FFT. Прежние ASM-рекомендации ниже — исторический контекст, не разрешение заменить обязательный forward. Текущий статус и преемственность: [R-002](R-002-multiplane-fresnel.md), [приём материалов](intake.md), [инженерные карточки](engineering-cards.md). Полные экспорты R-001-A/B ещё ожидаются.

**Состояние: план, НЕ выполнено.** Пороговые значения ниже — исходные инженерные предложения для double precision на малых тестах; независимый рецензент B должен проверить их применимость. В текущем проверенном Python отсутствуют torch/numpy/обе библиотеки. Установка больших зависимостей и запуск не входят в подготовку документов.

## T0 — установка и API/градиент smoke

Отдельная venv, без изменения рабочих окружений. Выбрать Python и точную CPU-версию torch, совместимые с командной средой; зафиксировать их в отчёте. После установки получить pip freeze. Первые кандидаты: torchoptics==1.0.2 и waveprop==0.0.12; установка обоих в общую среду не обязательна для независимой сверки.

Проверенный статически вход TorchOptics: `Field(data, wavelength=lambda_m, spacing=(dy,dx)).propagate_to_z(z, propagation_method="ASM", asm_pad=(py,px)).data`. `asm_pad` — число добавляемых отсчётов **с каждой стороны** каждой оси, не множитель размера. В проверенном default итоговый размер 5N; для общей сетки 2N при чётном N нужно добавление N/2 с каждой стороны. Публичный метод возвращает поле заданной геометрии, поэтому crop следует учитывать отдельно.

Вход waveprop: `from waveprop.rs import angular_spectrum`; `out, x, y = angular_spectrum(u_in, wv=lambda_m, d1=(dy,dx), dz=z, bandlimit=True, pad=True, device="cpu")`. Проверить этот вызов на установленном release и фактический dtype; не предполагать поддержку (B,C,H,W), если библиотека ожидает 2D. Передавать поэлементно через адаптер и явно тестировать batch, не менять научный смысл.

MRE: seed=42, CPU, 32x32, float64 phase -> complex128 input `exp(1j*phase)`, lambda=532e-9 м, dy=dx=8e-6 м, z=1e-3 м; это тестовая геометрия. Положительный неравномерный target. Forward -> abs(field)^2 -> scalar MSE -> backward. Вывести Python/torch/library, shape/dtype/device, finite, loss и норму градиента. Критерий: выход complex, нужной формы, finite; real gradient по фазе finite и ненулевой на невырожденном примере. Не оптимизировать полную энергию как loss: у унитарного оператора её градиент по фазе нулевой.

## T1 — тождество и аналитическая мода

- z=0, без спектральной маски/crop: U_out=U_in. Предлагаемый relative L2 <=1e-10 в complex128.
- Периодическая 32x32 сетка, без padding/crop/bandlimit, DFT-мода с целыми индексами (my,mx)=(1,2). f_y=my/(Ny*dy), f_x=mx/(Nx*dx), оба в распространяющемся спектре. Ожидание: U_out=U_in*exp(i*2pi*z*sqrt(lambda^-2-fx²-fy²)), relative L2 <=1e-7.
- Это тест знака/FFT, а не моделирование конечной апертуры. Полная комплексная ошибка проверяет и глобальную фазу; картинка интенсивности её не обнаружит.

## T2 — энергетический баланс

Сначала T1-мода на полной периодической сетке, все её моды распространяются, abs(H)=1: относительное изменение sum(abs(U)^2) <=1e-10 в double. Для физической мощности в скалярной параксиальной модели включать dx*dy.

Затем локализованное поле/апертура: измерить входную дискретную норму, полное padded output, crop и ROI до любых нормировок. Для того же полного поля P_crop<=P_full и P_ROI<=P_crop с численным допуском. Дефицит полного поля при bandlimit/evanescent decay учитывать отдельно; не требовать полного равенства с входом. Нельзя проверить P_full, если API вернул только crop: получить диагностический полный результат поддерживаемым способом, иначе явно отметить пропуск.

Отчёт: eta_input=P_ROI/P_in, eta_window=P_ROI/P_window, capture=P_window/P_in. Для разных шагов использовать площади ячеек. Это ещё не строгая оценка потока при высокой NA или для evanescent near field.

## T3 — градиент

Малая 8x8 CPU/float64 фаза, smooth nonzero input, z=1e-4 м, умеренные частоты. Весь путь Field->propagate->abs²->weighted scalar loss сохраняет autograd. `torch.autograd.gradcheck` по **real фазе**, eps=1e-6, atol=1e-5, rtol=1e-3, без фазового wrap/квантования/клипа в пути. Независимо сверить центральную конечную разность в нескольких пикселях. Проход не доказывает градиент по lambda/z/spacing.

## T4 — окно и sampling

Одна локализованная smooth апертура; фиксировать физические параметры и общий центральный ROI. Сначала увеличивать padding/окно с тем же шагом: 2N, 4N, при необходимости 8N. Затем уменьшать dx/dy при сохранённой физической апертуре/ROI. Явно учитывать центровку чётных/нечётных сеток и resampling.

Сравнить нормированные **для анализа формы** интенсивности и отдельно абсолютную энергию. Предлагаемый стартовый критерий сходимости ROI intensity relative L2 <1% между двумя последними разрешениями; при провале не объявлять исходную сетку годной. Один прогон на примере не допускает весь диапазон ТЗ.

## T5 — независимая сверка

Одинаковые физика/вход/выход, знаки/оси/площади ячеек, precision и согласованная спектральная поддержка. Сначала TorchOptics против waveprop, выровняв padding и отдельно показав эффект bandlimit; различие настроек не называть багом.

Затем хотя бы один эталон с другой ошибкой дискретизации: аналитический режим или сходящаяся Rayleigh–Sommerfeld direct integration на очень малой сетке/малом ROI. Источники для квадратуры: waveprop.rs.direct_integration/fft_di. Интеграцию самой waveprop также проверять с уменьшением шага и аналитическим пределом; это не абсолютная истина.

Для Airy-теста требуется круглая равномерная апертура, параксиальная фокусировка, разрешённое пятно и обоснованная область применимости. При невыполнении условий выбрать другой эталон. Значение 1.22*lambda*f/D нельзя применять ко всем входным пучкам.

## Артефакты и gate

Сохранить версии/commit всех реализаций, команды, hardware, seed, config (SI), input/output shape и шаги, dtype/device, настройки padding/bandlimit/crop, текст ошибок, target/field/phase/intensity и таблицу тестов. Никакого вывода о скорости, 200x или времени обучения из этих smoke-проверок.

**Решение о движке:** T0–T3 обязательны до интеграции; T4–T5 обязательны до научных заявлений на принятой геометрии. Не прошедший тест не обходить ослаблением допуска без причины/нового решения. По исчерпании 60–90 минут первичного spike приложить результат/блокер и не ломать рабочий baseline. При изменении физического диапазона пересмотреть приёмку.
