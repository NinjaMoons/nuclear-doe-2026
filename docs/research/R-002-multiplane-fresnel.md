## Минимальная математика, проверенная координатором

Для принятых exp(+ikz) и отрицательного знака DFT:

U_z(x,y) = exp(ikz)/(i lambda z) * exp[i*pi*(x²+y²)/(lambda z)] *
FFT_c{ U_0(u,v)*exp[i*pi*(u²+v²)/(lambda z)] } * dx_in*dy_in.

При обычном unnormalized forward FFT — множитель площади входной ячейки, при norm='ortho' дополнительно sqrt(Nx*Ny). FFT_c = fftshift(fft2(ifftshift(...))); проверять оси и центровку независимо, особенно нечётные прямоугольные сетки.

dx_out = lambda*z/(Nx*dx_in), dy_out = lambda*z/(Ny*dy_in). Для 128×128:

| z, мм | dx_out=dy_out, мкм | Период/ширина окна N*dx_out, мм |
| --- | --- | --- |
| 24.1 | 10.0165625 | 1.28212 |
| 25.3 | 10.5153125 | 1.34596 |
| 26.5 | 11.0140625 | 1.40980 |
| 27.7 | 11.5128125 | 1.47364 |

Это вычисленный вывод из выбранной дискретизации, не явно напечатанные в ТЗ шаги. Нельзя неявно считать четыре выхода одной сеткой 10 мкм. Четыре target могут трактоваться на четырёх соответствующих физических сетках; перевод на общий физический FOV — отдельное согласуемое resampling-решение, не исправление FFT.

Один U0=A_in*exp(i*phi) независимо распространяется на каждое абсолютное z. Не четыре независимых phi и не последовательный single-FFT каскад между соседними плоскостями: такой каскад меняет сетки/оператор.

L(phi;T)=sum_p w_p * ell(abs(F_zp(U0))²,T_p), сумма градиентов идёт в одну phi. Вид ell, масштаб T, веса и preprocessing являются инженерным выбором. Для raw MSE по intensity веса могут неявно смещаться из-за масштаба поля 1/z; фиксировать это отдельно. Произвольные четыре изображения не обязаны иметь точное решение одной фазовой маской.

## Реально выполненная малая проверка координатора

Reference-скрипт: reference/r002_numpy_reference.py. Команда: bundled Python 3.12.14, NumPy 2.3.5, CPU, seed=42. Не проектная .venv; PyTorch не установлен в проверенной .venv/bundled runtime.

- Сетки 4×6 и 5×7, dy=11 мкм, dx=9 мкм, все четыре z: FFT против прямой суммы exp[i*pi*((x-u)²+(y-v)²)/(lambda*z)]. 8 случаев, relative L2 **7.83e-15 … 1.764e-14**.
- Power ratio с площадями выходной/входной ячейки: **0.9999999999999994 … 1.0**.
- Одна общая random phase, сумма raw-MSE четырёх плоскостей: прямой аналитический gradient по четырём выбранным пикселям против central differences, eps=1e-5: max absolute error **2.161e-12**.
- Проверено только соответствие малых дискретных формул и chain rule. Это **не** PyTorch gradcheck, не тест кода #14/ASM PR #13, не обучение сети и не проверка непрерывного diffraction integral на 128×128.
- Евристическая граница входного chirp N*dx²/lambda = 24.06015 мм близка к z_min=24.1 мм. Это повод для Q02, не универсальный сертификат отсутствия aliasing. Выходная квадратичная фаза не меняет интенсивность, но важна для complex field/дальнейшего propagation.

## Переиспользование готового

[waveprop.fresnel.fresnel_one_step](https://github.com/ebezzam/waveprop/blob/84c3e7dd50c7193e4c069a7581740ecbf33a3167/waveprop/fresnel.py) подтверждён как NumPy structural reference (S06), MIT S02. Он вызывает NumPy exp и не является готовым autograd backend. Нечётные координаты/fftshift этого reference нельзя слепо перенести: проверять отдельными direct-sum тестами.

TorchOptics ASM_FRESNEL — transfer-function FFT/IFFT S01, не требуемый chirp/one-FFT алгоритм. Его можно использовать лишь для отдельного согласованного сравнения, а не заменить официальный forward.
