## Ночной протокол 7→8 ноября 2026 — ОБЯЗАТЕЛЬНО ПРОЧИТАТЬ

**Все Claude Code исполнители** до начала и после завершения каждой задачи читают [NIGHT_AGENT_PROTOCOL](docs/hackathon/NIGHT_AGENT_PROTOCOL.md), актуальную GitHub Issue и статусы других физических хостов. Протокол фиксирует прямое поручение Павла: самостоятельно выбирать следующие безопасные полезные задачи после DONE, не спрашивать разрешения на каждую исследовательскую гипотезу; не дублировать GPU-эксперименты, вести квоты с точным временем сброса и часовым поясом, сохранять checkpoint работы при лимите и иметь NEXT_ACTIVE/восстановление. Это уточняет прежнее ограничение AGENTS.md на исследовательские работы в пределах согласованного ночного плана, **не** отменяя запреты на неразрешённые данные, непроверенные релизы, платные расходы, TEST и запрещённый итеративный inference. Официальная отправка требует отдельной авторизации назначенного отправителя. Отчёт об ACK публиковать с реальными данными в своей Issue. Комментарий GitHub не запускает новый процесс или автоматическое пробуждение сессии.
